## What is NebulaFD?
NebulaFD is just another decompiler for Clickteam Fusion 2.5. It can convert an EXE to MFA or dump assets, such as images, sounds, fonts, and binary files.

## Installation
Installation is very easy: just download the latest release, extract the files, and open the EXE file. **Nebula FD Requires [.NET 6.0](https://dotnet.microsoft.com/en-us/download/dotnet/6.0) Desktop Runtime.**

## Usage
NebulaFD is easy to use and does not really need much of user input, just follow the instructions and you should be able to decompile any Clickteam Fusion game.

To get started, open `Nebula.exe` and drag and drop a Clickteam Fusion EXE, APK, DAT, or an open file structure (HTML/XNA).

After that, you should select a file-reader (Example: Normal, EXE, APK, CCN). If you are not sure, select the `Auto-Detect` option.

If everything goes well, you will be able to select a task, such as `MFA Parser` or `Asset Dumper`. Asset Dumper can dump images, sounds, fonts, and binary files, while MFA Parser extracts the MFA from the game.

> [!Note]  
> Decompiling is not always perfect. Images, sounds, and code might not match the original MFA. Larger games might take longer time to decompile.
